# 项目须知与贡献指南

## 1. 项目当前阶段
本项目目前处于**早期快速迭代阶段**。现阶段的所有技术路线、架构设计及美术视觉效果均处于探索与验证期，并非最终确定的方案。

## 2. 反馈与建议机制 (Issues)
欢迎通过提交 **Issue (议题)** 的方式参与项目讨论。如果您有以下想法，请积极反馈：
* **视觉与美术效果：** 针对界面设计、UI/UX 交互或视觉风格的改进建议。
* **技术与功能路径：** 针对现有功能实现逻辑、技术选型或发展方向的优化思路。

## 3. 代码贡献与功能申请 (Pull Requests)
* **暂不接受 PR：** 现阶段项目暂不接受任何形式的外部 Pull Request (拉取请求)。
* **新功能申请：** 若您需要新增某项功能，请提交 Issue 阐述具体需求与应用场景。
* **插件系统规划：** 我们正在加速开发插件化架构。将来开放插件功能后，您将能够通过编写插件来扩展系统功能。

感谢您对本项目的关注与支持！

# Project Notice & Contributing Guidelines

## 1. Current Project Stage
This project is currently in an **early, rapid-iteration phase**. All technical routes, architecture designs, and visual/art assets are in an exploratory and validation stage and do not represent the final solutions.

## 2. Feedback & Suggestions (Issues)
We welcome you to participate in project discussions by submitting an **Issue**. Please feel free to provide feedback if you have thoughts on:
* **Visuals & Art:** Suggestions for improving UI/UX design or visual style.
* **Technical & Functional Implementation:** Ideas for optimizing existing logic, technical stack choices, or the future direction of development.

## 3. Code Contributions & Feature Requests (Pull Requests)
* **No PRs Accepted Currently:** At this stage, the project is not accepting external Pull Requests in any form.
* **Feature Requests:** If you would like to request a new feature, please submit an Issue detailing the specific requirements and use cases.
* **Future Plugin System:** We are actively developing a plugin architecture. Once the plugin functionality is released, you will be able to extend the system's capabilities by writing your own plugins.

Thank you for your interest and support!
