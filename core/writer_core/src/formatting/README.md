# Formatting 模块

本模块实现纯文本的高性能排版与格式化分析。

## 核心功能

- **一键排版算法**：提供清理多余段首空格、尾部杂乱空白的排版工具。
- **纯文本绝对底线**：
  - **红线警告**：排版层**绝对不允许**为了首行缩进而往正文里物理插入任何空格（这会破坏纯文本干净度）。首行缩进是属于 UI 渲染层的展现职责（如 QTextDocument 的 QTextBlockFormat 缩进），物理存储的正文永远是纯文本。
  - **行空行保留**：排版策略必须保留用户连续的段落空行，不得盲目吞没用户的空行结构。
- **字数与事件统计分析**：以毫秒级响应分析高频写作的段落和字数变化。

## 关联文件

- `mod.rs`：排版暴露的业务方法与一键排版核心逻辑。
- `analyzer.rs`：执行高级写作行为和正文文本指标分析的纯领域算法。
