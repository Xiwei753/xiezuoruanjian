# Sync 同步模块

本模块管理多端网络同步与版本冲突合并。

## 核心功能

- **双引擎同步**：
  - **Git 引擎**：基于本地 Git 仓库，自动生成 commit、管理分支和解决拉取合并。
  - **GitHub API 引擎**：在移动端或受阻网络下，使用轻量化的 HTTP REST API 标准进行拉取、推送及令牌鉴权，绕过复杂的 libgit2 代理探测问题。
- **清单冲突解决**：在本地和远端发生章节冲突时，将冲突章节内容另存为 `.conflict` 冲突副本文件，绝对不采用野蛮覆盖用户本地稿件的做法。
- **网络状态诊断**：执行网络诊断探测，暴露结构化的同步详情。

## 关联文件

- `mod.rs`：提供同步任务、清单比较的聚合层。
- `git_backend.rs`：底层 Git 本地同步算法的 Rust 实现。
- `github_api.rs`：基于 HTTP REST 的 GitHub 同步方案实现。
- `conflict.rs`：冲突策略和副本隔离落盘逻辑。
