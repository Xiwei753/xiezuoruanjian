# 同步模块

本模块处理多设备间的数据同步，支持通过 Git 进行版本控制和云端备份。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义同步接口 |
| `engine.rs` | 同步引擎，实现具体的同步逻辑 |

## 功能说明

- **Git 同步**：通过 Git remote 进行版本控制
- **冲突处理**：自动检测和解决同步冲突
- **增量同步**：只同步变更部分，提升效率

## 依赖关系

- 依赖核心库的工作区和项目模块
- 被客户端的同步界面调用

## 使用说明

- 同步规则详见 `docs/sync_rules.md`
- 修改同步逻辑后需测试多设备场景
