# 同步服务模块 (Sync Service)

本模块是写作软件的核心同步服务实现。
唯一的同步业务真相来源（Single Source of Truth）。负责完整同步逻辑、生成 manifest、冲突判定。返回结果需为纯领域结构，不含有任何向前端输出的带有展示意图的格式化信息。

## 后端支持说明

- **默认后端**：GitHub API 后端（基于 GitHub API，适合大多数使用场景，无需本地克隆完整 Git 仓库，能提供更轻量级的同步）。
- **Git 后端**：基于 standard git 协议（通过 libgit2 库实现），用于自建服务器或兼容已有 Git 工作流，作为底层保留能力提供。
- **Fallback 机制声明**：**不存在任何自动降级/fallback 承诺**。当 Git 后端同步失败时，系统**不会**尝试自动切换到 GitHub API 后端，反之亦然。用户配置什么后端，就严格执行该后端的同步，同步失败则向用户报错并提示排查。
