# 思维导图模块

本模块管理作品的大纲、笔记和思维导图，帮助作者组织创作思路。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义思维导图接口 |
| `anchor.rs` | 锚点管理，处理节点定位 |
| `edit.rs` | 编辑操作，处理节点的增删改 |
| `graph.rs` | 图结构，管理节点和连接关系 |
| `layout.rs` | 布局算法，计算节点位置 |
| `migration.rs` | 数据迁移，处理版本兼容 |
| `snapshot.rs` | 快照功能，保存导图状态 |
| `storage.rs` | 存储层，持久化导图数据 |
| `validation.rs` | 数据验证，确保导图完整性 |

## 功能说明

- **节点管理**：创建、编辑、删除思维导图节点
- **层级结构**：支持多层级的树状结构
- **拖拽编辑**：支持拖拽调整节点位置和关系
- **导入导出**：支持多种格式的导入导出

## 依赖关系

- 依赖核心库的存储模块进行数据持久化
- 被客户端的思维导图界面调用
