# Project 模块

本模块管理核心实体生命周期：作品（Project）、卷（Volume）和章节（Chapter）。

## 核心职责

- **实体增删改查**：提供新增作品、分卷、新建章节的底层实现。
- **正文物理落盘与读写**：章节正文以原始纯文本形式在磁盘上存取。
- **安全性写入校验 (Empty Overwrite Check)**：
  - 核心提供防空文件覆盖拦截。
  - 普通保存若误传空字符串覆盖非空正文，核心会返回拦截错误 `EMPTY_OVERWRITE_BLOCKED`。
  - 用户显式清空必须调用专门的清空语义接口。

## 关联文件

- `mod.rs`：项目与章节实体的定义与行为逻辑。
- `chapter_store.rs`：控制物理正文读写和防空覆盖的读写安全层。
