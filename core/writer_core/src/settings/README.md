# 设置模块

本模块管理应用程序的所有用户偏好设置，包括编辑器配置、界面主题、同步选项等。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义设置管理接口 |
| `models.rs` | 设置数据模型，定义所有设置项的结构 |

## 功能说明

- **设置存储**：将用户偏好保存到本地文件
- **设置读取**：加载并应用用户配置
- **默认值管理**：为新用户提供合理的默认设置

## 依赖关系

- 依赖核心库的存储模块进行持久化
- 被客户端的设置界面和各功能模块调用

## 使用说明

- 新增设置项需在 `models.rs` 中定义数据结构
- 修改设置后需更新 `docs/settings_schema.md` 文档
