# 编辑器模块

本模块提供文本编辑相关功能，主要处理自动校正和文本转换。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义编辑器功能接口 |
| `autocorrect.rs` | 自动校正功能，处理标点符号转换、空格规范化等 |

## 功能说明

- **自动校正**：自动修正中英文标点混用、多余空格等问题
- **文本规范化**：统一文本格式，提升写作体验

## 依赖关系

- 依赖核心库的存储模块进行文件操作
- 被客户端的编辑器界面调用

## 使用说明

- 自动校正规则应在 `autocorrect.rs` 中统一管理
- 修改校正规则后需要添加对应的单元测试
