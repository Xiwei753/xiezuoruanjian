# 编辑器模块

本模块提供平台无关的编辑器语义，处理自动校正、文本转换、编辑事务和动画事件描述。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义编辑器功能接口 |
| `autocorrect.rs` | 自动校正功能，处理标点符号转换、空格规范化等 |
| `transaction.rs` | 统一编辑事务、选区、变更 diff 和动画事件描述 |

## 功能说明

- **自动校正**：自动修正中英文标点混用、多余空格等问题
- **文本规范化**：统一文本格式，提升写作体验
- **编辑事务**：用 `EditorTransaction` 统一描述旧文本、新文本、选区和变更原因
- **动画事件**：用 `EditorAnimationEvent` 只描述渲染层可以播放什么，不在 Core 内绘制

## 依赖关系

- 被客户端的编辑器界面调用
- 不依赖 Qt、Android、QML、输入法或任何平台绘制能力

## 使用说明

- 自动校正规则应在 `autocorrect.rs` 中统一管理
- 修改校正规则后需要添加对应的单元测试
- 平台端不得自行猜 diff；输入、删除、粘贴、撤销、重做、加载、格式化都应先转成 `EditorTransaction`
- Desktop/Android renderer 只能消费 transaction 和 animation event，自行处理本地文字布局与绘制
