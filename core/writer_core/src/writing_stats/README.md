# 写作统计模块

本模块记录和分析用户的写作数据，包括字数统计、写作时长、每日进度等。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义统计接口 |
| `api.rs` | 统计 API，提供数据查询接口 |
| `store.rs` | 数据存储，持久化统计数据 |
| `aggregate.rs` | 数据聚合，计算汇总统计 |

## 功能说明

- **字数统计**：实时统计当前章节和总字数
- **写作时长**：记录每次写作的持续时间
- **每日目标**：设置和追踪每日写作目标
- **历史趋势**：分析写作习惯和产出趋势

## 依赖关系

- 依赖核心库的存储模块保存统计数据
- 被客户端的统计界面和写作界面调用
