# 星图模块

本模块提供作品结构的可视化展示，以星图形式呈现章节、角色、场景之间的关系。

## 主要文件

| 文件 | 用途 |
|------|------|
| `mod.rs` | 模块入口，定义星图接口 |
| `types.rs` | 类型定义，定义星图中的节点和边 |
| `graph.rs` | 图算法，处理节点布局和关系计算 |

## 功能说明

- **节点管理**：创建、编辑、删除星图节点
- **关系连接**：建立和管理节点间的关系
- **布局算法**：自动计算节点位置
- **数据导出**：将星图数据转换为可视化格式

## 依赖关系

- 依赖核心库的项目和章节模块获取数据
- 被客户端的星图界面调用
