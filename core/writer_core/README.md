# writer_core — Rust 核心业务库

本目录是本项目的最底层，也是整个系统的业务真相源泉（Single Source of Truth）。

## 职责范围

- **文件 I/O 与工作区管理**：严格遵循 `workspace_format.md` 规范对本地磁盘进行读写。
- **项目、卷与章节生命周期**：处理作品的增删改查及防误删/清空逻辑。
- **数据同步核心**：包括 Git 本地处理、基于 Token 的 GitHub API 同步方案、清单比较和冲突合并策略。
- **格式化与字数统计规则**：段首缩进排版（但不改变原始纯文本）、字数和写作事件流的高性能分析。

## 目录结构说明

- `src/`：Rust 源码目录。
  - `facade.rs`：对外暴露的最高层统一门面 API 接口。
  - `workspace/`：工作区创建、校验、读取等底层文件结构管理。
  - `project/`：管理作品、分卷、章节的数据存储与逻辑层。
  - `sync/`：实现基于 Git 及 RESTful 的网络同步算法。
  - `settings/`：配置数据模型的校验与落盘（Settings Schema）。
  - `formatting/`：写作编辑排版算法和一键排版策略。
  - `api/`：UniFFI 及各平台调用的聚合暴露层。

## 架构红线

- **绝对禁止** 在此处引入任何 UI 动画、窗口管理器或平台相关界面渲染代码。
- **必须** 在每次修改后执行 `cargo test` 以保证高测试覆盖率。
