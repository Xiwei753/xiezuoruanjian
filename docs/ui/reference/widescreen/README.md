# 宽屏 UI 手稿基准

本目录是 Issue #829 的宽屏布局基准。这里的手稿优先级高于旧截图、旧注释和平台默认导航样式。

## 参考图

- `作品页.png`：宽屏一级导航、顶部动作区、作品卡和新建作品卡的位置关系。
- `设置页.png`：设置必须悬浮在打开前的页面上；顶部搜索，主体为两列设置区域。
- `左右缩回.png`：写作页左右工作区收起后的状态；正文保持在中央，不出现底部一级导航。
- `宽屏全打开.png`：写作页完整骨架：顶部编辑工具栏、左侧作品/卷/章节树、中央正文、右侧星图/AI 工具区。

## 硬约束

1. Workbench 宽屏没有底部一级导航。作品 / 星图 / 统计只放在左侧纵向导航。
2. HarmonyOS 不为了 HDS 底部沉浸光感保留错误的底栏；侧栏按普通宽屏导航绘制。
3. 写作页左右栏是工作区，不是独立页面；左栏和右栏都可以收起/展开。
4. 正文底部只放字数、进度、时间等状态信息，不放一级导航。
5. 设置是覆盖当前页面的悬浮层，不跳成新的全屏页面。
6. HarmonyOS 与 Linux Qt 共用同一空间结构；具体系统控件和材质可以不同。
7. 后续调尺寸、间距、字体、图标时，直接对照本目录手稿，不再根据文字自行重新设计。

## 当前骨架

Issue #829 第一轮只把结构钉死：Workbench 直接进入左侧导航壳，首页/工作区同步使用宽屏骨架，设置在 Workbench 使用两列悬浮布局。写作页继续复用现有七角色 Workbench（顶部三段 + 章节树 + 正文 + 工具面板 + 工具轨），后续只在这些插槽里继续对齐手稿。
