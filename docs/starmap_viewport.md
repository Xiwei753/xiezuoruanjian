# 星图视口协议 v2.0 (独立画布与跨画布 zoom 过渡)

## 目标

每张星图都是**独立的无限二维画布**，拥有自己的独立视角。用户通过连续 zoom 过渡在画布之间穿行：放大 Embed 入口进入子画布，缩小退出回到父画布。不存在"父画布里递归塞满子画布内容"的坐标链，也不存在"一台 root global camera 管所有层"的架构。

## Core 与平台边界

- Core 保存每张画布自己的节点/Embed 的 authored 文档坐标（`StarMapNode.position`、`StarMapEmbed.position`，精度 f64）。
- Core 保存导航路由（`StarMapNavigationRoute`）描述从根图到当前画布的语义路径。
- **Core 不保存镜头/相机/视口参数**：镜头位置、缩放比例、过渡阈值、动画时间线全部归各平台。
- 平台层负责：当前活动图的独立视角、Embed 入口标识的渲染策略、zoom 过渡动画、命中与手势。
- 平台层不回写任何镜头数据到 Core。缩放、平移、切换活动图都**不允许**改变 authored position。

## 独立视角协议

### 当前活动图

- **当前活动图拥有独立视角**：每层保存自己的镜头状态（缩放比例、平移偏移）。
- 不存在递归坐标链（world → local fit → root world → global camera → screen）。
- 不存在"父 Scene 必须真实显示完整 child Scene"的要求。
- 每张画布只保存自己节点与 Embed 的 authored 文档坐标，不关心其他画布的坐标空间。

### 跨画布 zoom 过渡

当用户聚焦一个 Embed 入口并持续放大时：

1. **放大阶段**：当前活动图的镜头持续放大，Embed 入口标识在屏幕上变大。
2. **切换阶段**：入口的**投影直径占当前视口短边达到进入阈值（70%）**时，平台执行连续过渡——当前活动图切换为 Embed 目标星图，新活动图以同一屏幕比例呈现（概览里看到的子图内容在切换后仍然占同样的屏幕大小与位置）。
3. **恢复阶段**：用户反向缩小、入口投影直径降到退出阈值（60%）时，活动图切换回父画布，镜头恢复到进入前保存的状态并继续按同一方向缩放。

阈值只比较"指针瞄准或已锁定的那个入口"，不因为鼠标停在别处缩放而意外进入别的子图。**镜头 zoom 数值本身绝不是层级切换依据**（zoom = 237 只是缩放倍率）；zoom 达到 70% 之类是旧实现的错误口径。

过渡阈值、动画曲线、过渡时长由各平台自行定义，不回写 Core。

### 退出导航

- `exit_canvas(route)`：弹出导航路由的最后一个段，回到上一层画布。
- 平台负责恢复上一层画布的镜头状态（进入前保存的缩放比例和偏移）。
- 返回按钮与反向缩小穿越使用同一套 Core 导航路由；平台按 routeKey（根 ID + 完整 segments）保存每层进入前的父镜头，同一目标图的不同 Embed 入口各自独立。

## Embed 入口标识在父图里的表现

未进入时，父图里的 Embed 入口只有两级表现，二者都不提供子画布的编辑能力：

| 级别 | 条件 | 渲染内容 | 可交互 |
| --- | --- | --- | --- |
| `shell` | 任何大小 | 正圆外壳、描边、标题、选中环 | 作为"进入子画布"的入口命中 |
| `preview` | 入口投影足够大 | 目标图真实数据的 fit-to-bounds 微缩概览（节点 / 边 / 子入口圆） | 否；整块仍按入口命中 |

- **进入后没有第三档嵌套交互**：活动画布切换为目标星图本身，圆壳、裁剪、入口边框全部消失，目标图是完整无边界画布；它的节点 / 边 / 文字是真实矢量对象，不是被放大的预览。
- 概览整体留在圆的内接安全区（约直径 60–70%），不需要圆形 FBO 遮罩 / 裁剪纹理；父图相机变化时按当前投影重画几何，不保存固定分辨率快照。
- **硬约束：分级绝不改变 Embed 的形状、world bounds 或 authored position。**
- Embed 的 world 几何恒定（正圆直径 200，与 `DEFAULT_EMBED_DIAMETER` 同值）；屏幕上多大只由当前活动相机投影决定，不写 Core。
- 投影太小时只是不画概览细节，不重建任何布局矩形、不改 authored position。
- 缩放只走显示变换，不许把缩放乘进布局尺寸属性。
- `preview` 整块不参与触摸竞争，当前活动图的手势必须完整穿过它。

### preview 与活动画布是同一张图

`preview` 不是"预览皮肤"，而是**目标图按进入比例的静态投影**：进入后换成同一张图的真实矢量对象，表达的对象身份完全一致——不应该"由圆变方"或"换一套颜色"。

投影太小时可以省掉文字，但**只省文字**：节点的形状和颜色一个都不改。

## 视觉焦点

焦点是"用户当前最关心的入口 / 画布"，由平台自行定义驱动条件（如入口投影大小 + 指针位置）。它只影响两件事：`preview` 是否绘制文字级细节、以及 zoom 过渡时的目标画布。焦点从不改变任何几何。

## 不同屏幕尺寸

- 屏幕尺寸只影响当前活动图的初始视角（"看一眼全貌"的起点）。
- 屏幕尺寸变化不重排 authored position，不重建 Embed 矩形。

## 缩放后的重叠

正常相机缩放**不触发任何碰撞规避、不推开邻居**。

- 稳定 world 几何 → 均匀相机变换 → 同层对象同比缩放。这才是"缩放"的语义。
- 只有当用户真的创建、移动、缩放了某个对象的 world bounds 时，才走局部碰撞规避 / 空位选择。
- 缩放不是布局变化。

## 相机范围

- 数值安全边界由各平台自行定义（它只防止数值/图形管线爆掉）。
- **边界不是层级切换依据**：任何 zoom 数值都不触发进入 / 退出子画布。
- 工具栏用**乘法**步进，保证各档手感一致。
- 双指捏合保持连续比例，并保持双指中心下的 world 锚点不动。
- 大倍率 / 大世界坐标下，平台应以视口中心作相对原点做投影，避免"巨大世界坐标 × 极大 zoom"的浮点抖动。

## 渲染与性能

- 活动画布实时绘制：连线 / 曲线用 `QtQuick.Shapes.ShapePath` 按当前投影生成路径，节点 / 子入口用矢量矩形与正圆，文字用实时 Text/TextInput。**不能**用连接线 Canvas 位图、子图 layer FBO 或缩略图纹理充当活动画布，也不允许把 1x 栅格化画面放大 N 倍。
- 线宽 / 文字字号采用确定的屏幕口径（按用户字号策略在屏幕像素上现算），不随预栅格化纹理缩放。
- `preview` 只随屏幕投影重画对应几何（不保存固定分辨率快照）；进入阈值之后始终用目标活动画布的真实矢量对象。
- `preview` 不创建可交互子场景、不挂手势、不往里递归。

## 跨平台一致性

- Core 侧的 Embed 语义、层数、authored position、导航路由在所有平台完全一致。
- 进入 / 退出阈值（70% / 60%，按入口投影直径占视口短边）与滞回带是平台层共享口径，不允许各平台各写一套。
- 平台层不得新增"折叠态矩形卡片"这类与 Android / Linux 不一致的表现。

## 禁止路线

- ❌ 用 LOD 改变对象几何（换形状、换尺寸、换 authored position）。
- ❌ 在 preview 里另写一套"差不多像"的样式数字。
- ❌ 把缩放乘进布局尺寸属性（导致渲染引擎巨型缓冲）。
- ❌ 缩放时跑碰撞规避或推开邻居（缩放不是布局变化）。
- ❌ `opacity(0)` 假装折叠 / "先建好再缩到看不见"。
- ❌ 在 Rust 内部把 DTO 转 JSON 再解析回来。
- ❌ **Core 里出现任何视口、相机、投影、缩放相关的字段**。
- ❌ **假设子画布内容递归塞进父画布坐标空间**（旧递归容器空间契约已淘汰）。
- ❌ **假设存在 root global camera**（每张画布拥有独立视角）。
- ❌ **把"当前画布"实现成父 Embed 里嵌套的完整交互子场景**：未进入时只有微缩概览。
- ❌ **用 zoom 数值、画布面积或某个递归 Container 的尺寸当进入 / 退出阈值**：只按入口投影直径占视口短边。
- ❌ **用子图 ID 当相机 / 进入上下文的 key**：必须用 routeKey（根 ID + 完整 segments），同一目标图的不同入口各自独立。
- ❌ **用清空 pan/zoom、切页面重载制造跳帧**；进入 / 退出必须保持画面连续并恢复父镜头。
