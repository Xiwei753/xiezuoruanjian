# 手工验收清单

在进行重大修改或发布新版本前，请执行以下测试步骤，以确认核心功能正常工作。

## 1. 启动与更新
- [ ] 运行 `./tool/update_project.sh`，确认能顺利更新代码并执行检查。
- [ ] 运行 `./tool/run_linux_release.sh`，确认能以 Release 模式正常启动。
- [ ] 运行 `./tool/build_linux_release.sh`，确认能成功构建 Linux Release 包。

## 2. 作品管理
- [ ] 启动应用，确认默认进入“作品管理页”。
- [ ] 测试“新建作品”，能够成功创建多个新作品。
- [ ] 测试“打开指定作品”，确认能正确进入对应的作品工作区。
- [ ] 重启应用，测试“继续上次写作”，确认能自动打开最后一次操作的作品。
- [ ] 模拟 `lastOpenedProjectId` 不存在或失效的情况，确认能回退（fallback）到作品管理页。

## 3. 章节
- [ ] 测试“新建章节”，确认新章节在列表中出现并能编辑。
- [ ] 测试“切换章节”，确认编辑器内容正确切换，且不会丢失未保存的修改。
- [ ] 测试“删除章节”，确认章节被移动到 `trash` 目录，而不是直接删除。
- [ ] 测试“保存章节”，确认保存功能正常（左下角状态提示成功）。
- [ ] 测试“自动保存”，等待设定的时间间隔后，确认当前章节自动保存。

## 4. 编辑器设置
- [ ] 在设置中修改“字号”，确认编辑器文字大小实时生效。
- [ ] 在设置中修改“行高”，确认编辑器行高实时生效。
- [ ] 在设置中修改“正文宽度”，确认编辑器显示宽度实时生效。
- [ ] 开启/关闭“平滑滚动”，确认滚动表现符合预期。
- [ ] 开启/关闭“输入动画”，确认打字时的动画特效符合预期。
- [ ] 确认光标反馈和位置跟踪正常。

## 5. Linux 输入法 (重点诊断)
对于 Fedora KDE Wayland + fcitx5 推荐环境：
- [ ] 检查运行环境是否使用了以下配置：
  - `GTK_IM_MODULE` 设为空
  - `QT_IM_MODULE` 设为空
  - `SDL_IM_MODULE` 设为空
  - `XMODIFIERS=@im=fcitx`
- [ ] 使用中文输入法（fcitx5）输入测试文本，**确认候选框没有出现异常抽搐或闪烁**。
- [ ] 打开设置页面的“日志/诊断”区域，确认是否正确显示了上述环境变量的信息。

## 6. 自动保存与防冲突
- [ ] 键入新内容后，确认状态栏显示“未保存”。
- [ ] 等待达到自动保存间隔后，确认状态栏变为“已保存”。
- [ ] 在中文输入法（composing）处于活动状态（拼音未上屏）时，等待超过自动保存时间，**确认没有触发自动保存**，只有当拼音上屏后才触发。
- [ ] 模拟保存失败（如手动锁死文件），确认能弹出“保存失败”的提示。

## 7. 日志与安全
- [ ] 确认 `writer_app_workspace/app-meta/logs/app.log` 日志文件存在。
- [ ] 检查日志文件，**确认其中绝不包含用户小说的正文内容**。
- [ ] 检查日志文件，**确认其中绝不包含 API Key / Token 等敏感凭证**（应被 `***` 遮蔽）。
- [ ] 使用“设置 -> 诊断导出”功能收集诊断包，确认能够顺利导出并成功脱敏。
