# Android 客户端实机测试流程

> **注意**：测试 APK 必须通过执行 `./tools/build_android.sh` 构建生成，不能使用 Android Studio 的纯 Gradle 构建（这会生成缺失 Rust JNI `libwriter_core_jni.so` 的不可用包）。

## 测试步骤

1. 启动应用。
2. 点击“新建作品”，输入作品名，确认作品创建成功。
3. 进入该作品，确认自动出现的默认卷为“第一卷”。
4. 点击“新建章节”，进入编辑器。
5. 在编辑器中输入一段中文，等待自动保存触发（约 1.5 秒），确认提示为“已保存”。
6. 返回列表，重新打开刚编辑的章节，确认内容依然存在。
7. 完全杀掉应用进程，再次打开应用。
8. 确认刚才的作品、章节及内容一切都在。
9. 点击“设置”，尝试修改“字体大小”、“行距”及“主题模式”。
10. 返回编辑器，确认所作设置（字体、行距等）已正确生效。
