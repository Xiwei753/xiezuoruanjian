# Client Feature Matrix

| Feature | Android Native | Linux Native |
| :--- | :--- | :--- |
| UI Framework | Kotlin / Views | Qt / QML / Rust |
| Editor Component | Native EditText | QML TextArea |
| Rust Core | Yes (Facade/Bindings) | Yes |

| Sync Implementation | TBD (via Core) | TBD (via Core) |
| Status | MVP / In Progress | MVP / In Progress |

*Note: The Flutter Legacy prototype has been removed entirely. Android Native is the active client MVP. Linux Native is also in progress with a Rust Qt/QML implementation.*
